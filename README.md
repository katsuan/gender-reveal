# 👶 ジェンダーリビール 〜BabyQ〜

英字は BabyQ（Baby＋Q。Q は「クイズ（Question）」：男の子？女の子？）。おくるん＝OQRN・キロっく＝kiloQ と同じく Q を絵にしたロゴを使う。

アイコン（`icon.svg`・`icon-32.png`・`apple-touch-icon.png`・`icon-512.png`・`icon-maskable-512.png`）・横長のロゴ（`logo.svg`）・作成ページを共有したときの画像（`ogp-create.png`）は `python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`。GitHub のリポジトリ名は line-share）の `tools/brandkit.py`）。男の子の青 → 女の子のピンクのグラデーションに、白い輪の中の赤ちゃんの顔と右下のしっぽで Q。受け取る人の発表ページ（index.html）の共有画像は、性別をヒミツにしたプレゼントの絵（`ogp.png`）のまま。名前とロゴは作成ページにだけ出す。ホーム画面に追加したとき用に `manifest.webmanifest`。

おくるんのトップの「ほかのツール」（line-share の `data/hub-links.json`）には「ジェンダーリビール 〜BabyQ〜」として、このアイコン付きで載せている。


ジェンダーリビール(性別発表)用の静的サイト。GitHub Pages でそのまま動きます。

- 出産予定日までのカウントダウン&妊娠週数バー
- 予定日・発表日がわかるカレンダー
- プレゼントをタップ(回数は設定可) → 暗転&心音 → 紙吹雪で発表
- 発表解禁日時を指定すると、それまでボタンがロック

- 発表後の画面の「📷 画像で保存」で、結果（性別・名前・メッセージ・予定日までの日数）を 1080×1350 の画像にして保存できる（長押し・共有メニュー・ダウンロード）


作成ページ（`create.html`）の部品（見出しの行・カード・入力欄・小さいボタン・開閉）は、おくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`。使い方はおくるんの README）。色はロゴのうす紫（`:root` の `--ls-accent` など）。男の子の青 → 女の子のピンクのグラデーション（大きな「作る」ボタン・性別の選び方・見出し）はジェンダーリビールにしかない見た目なので、そのまま。受け取る人の発表ページ（`index.html`）は、プレゼントの演出そのものなので Q キットを使わない。
## 使い方

`create.html` をひらいてフォームに入力 → シェア用URLを作成。

### 性別を隠す仕組み

- 作成ページのURLは `#` の後ろに詰めたバイナリを入れた圧縮形式(v3)です。`#` 以降はサーバーに送られません
  - 2020年より前の予定日など v3 で表せない値のときだけ、従来の `?p=` 形式(v2)で作ります
- 性別・赤ちゃんの名前・メッセージは **AES-GCM で暗号化**。性別は固定長のコードなので男の子/女の子で長さは同じです
- **合言葉なし**：復号キーがURL末尾に入るため見た目ではわからないが、技術的には解析可能
- **合言葉あり(おすすめ)**：キーがURLに含まれないので、合言葉を知らないと解析しても読めません。発表ボタンを押すと入力欄が出ます
- 予定日・パパママの名前など公開情報は暗号化せずにURLに入ります(合言葉入力前にカウントダウンを出すため)
- 開いた直後にアドレスバーからパラメータを消して短く見せます。中身はそのタブの sessionStorage に置くので再読み込みしても表示でき、共有ボタンは元のURLを使います
- 旧形式(`?p=...` の v2、`?d=...&s=v1...` の v1)のURLも引き続き開けます
- バイナリ構成の詳細は `create.html` の `buildTokenV3` と `params.js` の `readV3` のコメントを参照
- URL の中身は `params.js` で、決まった項目・形・長さにそろえてから使う（色は色の形だけ）。名前などが入ったページは検索に出さない
- 発表のページのカレンダーは `calendar.js`（その月のマスと曜日の並び）。はじめは日曜はじまり、カレンダーの下の「月曜はじまりにする」で切りかえ（この端末に覚える）
- テスト：`node --test test/`（作る画面の v3 の作り方で作ったリンクを読む・壊れた中身でも落ちない）

## クエリパラメータ

| キー | 例 | 説明 |
|---|---|---|
| `gender` | `boy` / `girl` / `twins-boys` / `twins-girls` / `twins-mixed` / `twins` / `custom` | 性別(必須)。`twins` は性別ナイショの双子 |
| `due` | `2027-02-14` | 出産予定日 |
| `reveal` | `2026-12-24T19:00` | 発表解禁日時。未来ならロック |
| `dad` / `mom` | `太郎` | 表示名 |
| `name` | `べびちゃん` | 赤ちゃんの名前・愛称(入力どおり表示) |
| `title` | `ベビーの性別発表` | タイトル |
| `taps` | `10` | プレゼントを開けるタップ回数(1〜20、既定5) |
| `msg` | `元気に生まれてきてね！` | 発表後のメッセージ |
| `label` / `emoji` / `color` | `男の子と女の子！` / `👦👧` / `#f5c542` | `custom` 時の表示 |
| `boyColor` / `girlColor` | `#5aa9e6` | テーマ色の上書き |
| `#…` | base64url | 作成ページが出力する圧縮形式(v3)。上記すべてを1つにまとめたもの |
| `p` | base64url | 1つ前の短縮形式(v2、互換用) |
| `d` / `s` | — | 旧形式(互換用) |

手動で作る場合の平文例(テスト用):

```
index.html?gender=girl&due=2027-02-14&dad=太郎&mom=花子&name=べびちゃん
```

## カスタマイズ

色・サイズは `index.html` 冒頭の `:root` の CSS 変数で一括変更できます。
タップ回数の既定値は JS 冒頭の `DEFAULT_TAPS` です。

## 紹介の窓口

「📤 ジェンダーリビールを紹介する」（作成ページのいちばん下）は、おくるんの `shared/tool-share.js`（`data-tool="babyq"`）。押すとおくるんで紫の紹介カードを作って LINE に送れる（リンクのシェアも選べる）。中身は line-share の `data/hub-links.json` の `key: "babyq"`。
